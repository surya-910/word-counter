# Number Guessing Game & Word Counter

## Project Description

This is a beginner-friendly Python application that combines an interactive number guessing game with a text file word counter tool.

## Features

- Random number generation using the random module
- Number guessing game
- Attempt counter and scoring system
- Text file reading
- Word frequency analysis
- Basic string manipulation

## Technologies Used

- Python 3
- Python IDLE

## Concepts Covered

- Variables and data types
- Conditional statements
- Loops
- Random module
- File handling
- String manipulation
- Dictionaries

## How to Run

1. Download the Python file.
2. Install Python 3.
3. Open the file using Python IDLE.
4. Press F5 to run the program.
5. Provide a text file when using the word counter feature.
